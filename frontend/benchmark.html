How to read this

M3 leads 8 of 12, not all 12WSL2 on the i5 recorded lower medians for X3DH responder, SQLite indexed read, and both WebSocket ACK tests. The M3 figures are user-reported and do not show Halonyx is tuned for Apple Silicon.
WSL2 SQLite result needs a controlled rerunIndexed read is 88.90 µs under WSL2 versus 336.1 µs native. Filesystem location, virtualization and runtime version are all candidates. The data alone does not identify the cause.
Runtime versions differNative i5 used Node.js v26.12.0 and WSL2 used v26.13.0, while Ryzen 7 (v24.19.0), M3 (v24.22.2) and i3 (v24.22.1) used the v24 line. Treat cross-machine gaps as observations, not CPU-only comparisons.
Synthetic and loopback scopeSQLite uses deterministic synthetic fixtures. WebSocket and pipeline tests run in a single-process loopback harness, so they say nothing about relay or Internet latency. Browser painting and relay authentication are excluded.
Why mediansSome measurements vary widely. The detailed WSL2 report also has mean, percentiles, SD/CV, throughput and run information.
